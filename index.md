# VOD Clipper

VOD Clipper is a personal desktop tool that cuts highlights from Twitch VODs into short vertical clips (1080x1920) with subtitles and suggests a title, description and hashtags. It runs locally on the computer of its developer. There is no server, no public website and no user account system.

Optionally, the tool can publish a finished clip to the developer's own TikTok account through the TikTok Content Posting API (Direct Post). Every upload is started manually after the clip has been reviewed, and every post requires an explicit confirmation by the user.
