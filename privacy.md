# VOD Clipper - Privacy Policy

Last updated: 19 November 2026

## 1. Who is responsible

VOD Clipper is a personal desktop tool run by its developer on his own computer. There is no VOD Clipper server and no user database. Contact: open an issue in the GitHub repository tutorial509737-sudo/tutorial509737-sudo.github.io.

## 2. Data processed locally

The tool processes Twitch VODs, their public chat logs and the audio of the stream on the developer's own computer. Downloaded files, transcripts and rendered clips are stored only in a local folder on that computer and are not uploaded anywhere, except as described below.

## 3. TikTok data

When the developer connects his own TikTok account with TikTok Login Kit, the tool receives an access token and a refresh token and reads the basic profile information of that account (display name). The tokens are stored in a local file on the developer's computer and are used only to call the TikTok Content Posting API for that account. The tool does not collect data about any other TikTok user, does not share TikTok data with third parties and does not use it for advertising or analytics. The developer can revoke access at any time in the TikTok app under Security and permissions, and can delete the local token file.

## 4. Optional AI text suggestions

If an API key is configured, a short text summary of a clip (transcript excerpt and chat summary) is sent to the Anthropic API to generate a title, description and hashtags. Without an API key, simple local rules are used and nothing is sent.

## 5. Retention and deletion

All data stays on the local computer until the developer deletes the files. Deleting the local data folder removes all clips, transcripts and tokens.

## 6. Children

The tool is not directed at children and is not offered to the public.

## 7. Changes

This policy may be updated. The current version is always available at https://tutorial509737-sudo.github.io/privacy.html
